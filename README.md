# 하루칸 — 바탕화면 캘린더 · 할 일 · 유튜브 작업 관리자 (Windows)

디자인 시안 **B 세트(페이퍼 플래너)** 를 그대로 옮긴 Windows 데스크톱 프로그램입니다.
트레이에 상주하면서 바탕화면 위젯을 띄우고, 클릭하면 플래너 창이 열립니다.

## 구성

| 화면 | 하는 일 |
| --- | --- |
| **바탕화면 위젯** | 달력 · 오늘 할 일(체크, 빠른 추가) · 이번 주 작업량. 위젯마다 닫기, 트레이에서 다시 켜기, 끌어서 위치 이동 |
| **트레이** | 클릭 → 플래너 열기 / 우클릭 → 위젯 선택, 위치 고정, 투명도, 항상 위, Windows 시작 시 실행, 종료. 남은 할 일 수 배지 |
| **1 · 주간** | 월~일 7칸, 할 일 체크 · 끌어서 다른 요일로 이동 · 빈 칸 더블클릭 추가, 사진 · 링크 카드(마우스 올리면 [유튜브로]), 이번 주 목표, 미룬 일 한 번에 다음 주로 |
| **2 · 월간** | 달력(공휴일 표시), 칸 클릭 → 그 주, `+` → 바로 추가, 카테고리별 완료, 이번 달 목표, 이달의 유튜브 |
| **3 · 할 일** | 오늘/이번 주/예정/날짜 없음/완료, 카테고리 · 첨부 필터, 자연어 입력, 상세(세부 단계 · 사진 끌어놓기 · 링크 · 메모) |
| **4 · 작업** | 끝낸 일 스크랩북, 기간별 완료 수 · 연속 일수 · 날짜별 그래프 |
| **5 · 아이디어** | 아이디어 → 줄거리 → 콘티 → 완성 칸반(끌어서 이동), 폴더 · 태그, 콘티 컷 진행, 할 일로 만들기 |
| **6 · 링크** | 붙여넣으면 자동 인식(유튜브 롱폼/숏폼 · 노션 · 사이트), 썸네일 · 제목 자동, 날짜 · 할 일에 연결 |
| **7 · 유튜브** | 구독자 · 조회수 · 좋아요 · 이번 달 업로드 · 다음 공개, 2주 업로드 일정, 조회수 그래프, 롱폼/숏폼 목록 |

### 자연어 입력
`내일 3시 샘플 촬영 #작업` → 내일 15:00, 카테고리 ‘작업’.
`오늘 · 내일 · 모레 · 3일 뒤 · 금요일 · 다음주 월요일 · 10월 12일 · 10/12`, `오전/오후 N시 (M분|반) · 14:30`, `#카테고리` 를 인식합니다.

### 단축키
- `Ctrl+Alt+N` 어디서든 빠른 할 일 추가
- `Ctrl+N` 할 일 추가 · `Ctrl+F` 검색 · `Ctrl+1~7` 탭 이동 · `Ctrl+,` 설정
- 주간 · 월간: `←` `→` 이전/다음, `T` 오늘 / 할 일: `↑` `↓` 선택, `Space` 완료, `Delete` 삭제

## 설치 (Windows 10/11)

GitHub Actions가 Windows에서 자동으로 빌드합니다.

1. 저장소의 **Actions › Windows 빌드** 에서 최신 실행을 열고, 아래 **Artifacts › Harukan-Windows** 를 내려받습니다.
   (`v1.0.0` 같은 태그를 푸시하면 **Releases** 에도 올라갑니다.)
2. `Harukan-Setup-1.0.0.exe` — 설치형 (시작 메뉴 · 바탕화면 바로가기)
   `Harukan-Portable-1.0.0.exe` — 설치 없이 바로 실행
3. 코드 서명이 없어서 처음 실행할 때 SmartScreen이 뜨면 **추가 정보 › 실행** 을 누르세요.

## 화면 크기
1920×1080 기준으로 본문 13~14px로 잡았습니다. Windows 배율이 125% 이상이면 자동으로 조금 줄여 보여 주고,
**설정 › 글자 · 화면 크기** 에서 80~120%로 바꿀 수 있습니다.

## 유튜브 채널 연결 (선택)
키 없이도 링크를 붙여넣으면 제목 · 썸네일이 채워집니다. 구독자 · 조회수 · 길이까지 가져오려면:
1. [Google Cloud Console](https://console.cloud.google.com/) 에서 프로젝트를 만들고 **YouTube Data API v3** 를 사용 설정
2. **사용자 인증 정보 › API 키** 만들기
3. 하루칸 **설정 › 유튜브 채널 연결** 에 API 키와 채널 ID(UC…) 또는 @핸들 입력 → **지금 동기화**

예약(비공개) 영상은 API 키로 읽을 수 없어서 **유튜브 › + 영상 일정** 으로 직접 넣습니다. 매일 동기화하면 일별 조회수 그래프가 쌓입니다.

## 데이터
모든 데이터는 이 PC의 `%APPDATA%\하루칸\harukan-data.json` 에 저장되고, 사진은 같은 폴더의 `photos\` 에 복사됩니다.
하루 한 번 `backups\` 에 자동 백업(최근 14일)하며, **설정 › 데이터** 에서 내보내기 · 가져오기를 할 수 있습니다.

## 개발

```bash
npm install
npm start            # 개발 실행
npm run dist         # Windows 설치파일 + 포터블 exe (Windows에서 실행, 또는 Wine 필요)
npm run icons        # assets/ 아이콘 다시 만들기
```

- `src/main` — Electron 메인 프로세스 (트레이, 위젯 · 플래너 · 빠른 추가 창, 저장소, 유튜브 API)
- `src/renderer` — 화면 (`app.*` 플래너, `widget.*` 위젯, `quick.*` 빠른 추가, `views/` 탭별 화면, `lib/` 공용)
